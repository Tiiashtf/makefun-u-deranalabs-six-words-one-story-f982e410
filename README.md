One complete story in exactly six words, written by a program to
`/output/entry.txt`:

> **He remembered everything. Except her name.**

A man whose memory never failed him loses the one name that mattered
most — a whole life of remembering, reversed in the last three words.
The reader fills in who she was, and what it cost him to forget her.

## Run it

```sh
python3 main.py
```

`main.py` is Python 3.13, standard library only, no network. It writes
`/output/entry.txt` (42 characters, six words) and writes the same bytes
on every run; it clears only the contents of the output directory, never
the directory itself, and it refuses to write a story that is not exactly
six words within the 1–60 character gate.
